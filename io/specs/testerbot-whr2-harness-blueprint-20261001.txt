## PNG decode + sampling (inline these Python functions EXACTLY)
def decode_png(data_url): minimal PNG reader 8-bit RGB/RGBA non-interlaced from a data URL — base64.b64decode(data_url.split(",",1)[1]); verify magic b"\x89PNG\r\n\x1a\n"; walk chunks (ln,typ = struct.unpack(">I4s", raw[pos:pos+8]); body = raw[pos+8:pos+8+ln]); IHDR: w,h,depth,ctype = struct.unpack(">IIBB", body[:10]); IDAT: idat += body; pos += 12 + ln; require depth==8 and ctype in (2,6); bpp = 3 if ctype==2 else 4; stride = w*bpp; data = zlib.decompress(idat); unfilter per-row: f = data[p]; line = bytearray(data[p:p+stride]); filters 0..4 standard PNG (1=Sub,2=Up,3=Average,4=Paeth with standard a/b/c and paeth predictor); out[y*stride:y*stride+stride] = line; prev = line. Return (w, h, bytes(out), bpp).
def mean_luma(img, w, h, bpp, x0, y0, x1, y1): mean of 0.2126*R + 0.7152*G + 0.0722*B over clipped integer box; alpha band (bpp==4) skipped if 0.
def sample_ring(img, w, h, bpp, cx, cy, r0, r1, exclude): luminance mean over pixels with r0 <= dist <= r1, skipping pixels inside exclude box (cx±ex, cy±ex) and out-of-bounds.
