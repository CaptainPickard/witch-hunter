# AB1 ICON-LANE BRIEF (IO/asset lane - separate from the builder brief)

Lane owner: IO (not Astrabot, not the code builder). Per Nicko's AB1 order:
"icon generation is IO/asset-lane work - brief it separately, generate,
commit PNGs, and only then dispatch the builder to wire them."
Builder brief of record: io/missions/2026-10-07-cc-ab1-actionbar-spells.md
(v2, 72a8e31). This file covers ONLY the icon asset unit.

## Deliverable

16 icons, 48x48 PNG each, in prototype/js/icons/ + one generated registry
js/icons-data.js (data-URI map id -> png; window.WH_ICONS). The builder
wires the registry; it NEVER touches the PNGs.

List (CONFIG ids): roundShield, magicGlove, longsword, torch, healthPotion,
bandage, graveSoup, blandMush, firebolt, radiance, wildMushroom, graveMoss,
boneShard, forestHerb, deadwood, stolenCoin.

## Pipeline

- ITEM icons from EXISTING GLBs (roundShield, longsword, torch):
  pure-Python ortho 3/4 render (scratch/tree_ortho.py painter pattern,
  per-face texture/COLOR_0 sampling), fixed 3/4 angle, flat light,
  downscale NEAREST to 48, 5-bit posterize. No blender in container (none
  exists) - no blender anywhere in this lane.
- GENERATED icons (magicGlove - NO glove mesh exists, the worn glove is a
  placeholder caster-glow; spell icons firebolt/radiance - no meshes; the
  10 small inventory items): image_generate base art -> pixelize pass
  (pad to 512, NEAREST downscale to 48, 5-bit posterize). Spell icons must
  read at 24px HUD size.
- Art law (binding): 512 source max, NEAREST downscale, 5-bit posterize,
  darkwood palette, ONE accent per icon - amber human fire/spells, cyan
  magic (glove), pale gold radiance, red pact (none this round). Torch
  flame amber. Shield/sword steel/wood, no accent.
- QA: IO vision-analyzes its own sheet/layout mid-lane; final look gated by
  Nicko's playtest of the wired bar (no harness anywhere - Nicko's
  playtest is the only test).
