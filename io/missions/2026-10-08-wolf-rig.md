## 1. GOAL

Produce art-direction/3d/assets/races_regen/rigged/wolf.rigged.glb:
- Skeleton (ONE topology, these EXACT names; bind pose = the model's
  standing pose):

  - Tail1, Tail2, Tail3
  - FL_UpperLeg, FL_Leg, FL_Foot (Front-Left; FL/FR/BL/BR pattern)
- Skinning: smooth weights, max 4 influences/vertex; capsule-region fallback
  rule from the skill (bone capsules at bind pose, region = min distance/
  radius; only region bone + parent/children keep weight; rigid below
  threshold ~0.65). Jaw/Tail weights must NOT grab neck/chest vertices.
- SIX clips (named EXACTLY, one Action each):
  1. WH_Wolf_Idle — standing, breathing (chest scale/dip ~3%), subtle ear
    /head sway, tail sway slow; 3s loop, seamless (first frame == last).
  2. WH_Wolf_Walk — legged walk FL/BR then FR/BL diagonal-pair cadence,
     body bob minimal, tail sway syncs with stride; ~1.0s loop; IN PLACE.
  3. WH_Wolf_Run — gallop (gather + extend two-beat), bigger spine pitch,
     head lower/forward; ~0.55s loop; IN PLACE.
  4. WH_Wolf_Attack1 — lunge bite: windup (rear weight shift, head back,
     jaw opens ~35deg), strike (forward lunge of head+neck, jaw SNAP shut at
     contact), recover (settle to stance); ~0.7s; START AND END IN the idle
     stance (clean chain in/out).
  5. WH_Wolf_Hit — recoil: head shake + body dip, quick; ~0.4s; ends in
     stance.
  6. WH_Wolf_Death — buckle: legs fold under, body rolls slightly to one
     side, settles FLAT on the ground; ~1.1s; terminal pose = lying on
     side, tail limp. (NOTE the Mixamo zombie lesson: the clip must END
     PRONE, and the verifier must assert the end pose IS the prone rest —
     naming is not terminal.)
- ALL clips start and end at/near the idle stance (except Death = prone);
  NO root motion anywhere; Root keyed identity on every frame.

## 2. BYTE-SURGICAL CONTRACT (the append law)

- The deliverable is built FROM the raw intake: import wolf.glb, add
  skeleton + skin + clips, export to a TEMP GLB, then append/merge into
  the canonical deliverable via the glb_append_clips.py PATTERN.
- HOWEVER: this is a first rig (no prior clips) — so the simpler and
  CORRECT shape here is: build the rigged GLB from raw + skeleton in ONE
  Blender export, then RUN THE APPEND PATTERN'S VERIFY SCRIPT against
  it (mesh/UV/texture/material must be EXACTLY the raw's; only added:
  skin JOINTS/WEIGHTS, armature nodes, animations, inverseBindMatrices).
- VERIFY GATE (script asserts; all must pass):
  - Mesh: vertex count 13,085, tri count 20,060; positions/normals/UVs
    bitwise-equal to the raw (allow < 1.2e-5 float drift, report actual).
  - Texture bytes: bitwise-equal to the embedded atlas.
  - Material: same PBR fields (baseColorTexture present).
  - Skins: 1 skin, joint count = bone count above (report it).
  - Clips: 6, names exactly as listed; per-clip channel count =
    (animated bone count x T/R/S channels); durations within 5% of spec'd
    (3s / 1s / 0.55s / 0.7s / 0.4s / 1.1s).
  - WH_Wolf_Death end pose: assert the LAST frame's root height indicates
    prone (body height above ground < 35% of the standing rest height —
    measure it, don't trust the name).
  - Idle/Walk/Run/Attack1/Hit: first-frame bone transforms == last-frame
    (loop seamless; Death exempt, terminal).
