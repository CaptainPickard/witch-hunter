# Generated-art provenance and usage policy

All raster art in this repository (docs/planning reference notes aside)
was AI-generated during pre-production for the Witch Hunter project by
CaptainPickard using OpenAI image models (gpt-image-2) directed by IO
(Hermes Agent), following the locked art register in
docs/planning/02-art-style.md and docs/planning/24-art-bible.md.

- Concept frames (art-direction/concepts/, concepts-web/) are directional
  concept art for the project. They are not in-game assets.
- Sprite frames and atlases (art-direction/sprites/) are pilot artifacts
  demonstrating the production pipeline.
- The art register itself (composition grammar, palette law, prompt
  grammar) is original project documentation and is the reproducible
  asset.

No third-party copyrighted characters, logos, or trademarks are
depicted. External reference images collected during style research are
NOT included in this repo; only the project's own generated frames.

If this project moves toward distribution, generated art should be
re-reviewed against the chosen store's AI-content disclosure policies.
